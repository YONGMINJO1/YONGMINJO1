<summary><b>🐾 Pettact — 구현 & 문제 해결 보기</b></summary>
<br>

**주요 구현**
- 반려동물 케어 상품 CRUD, 장바구니, 주문 흐름 API 설계·구현
- Toss Payments 결제 API 연동, 요청·응답 흐름 설계 및 예외 처리

**문제 해결**
- **Toss 결제 요청 값이 누락되던 문제**
  → 원인: URL 파라미터로 전달하면서 데이터 타입 불일치
  → 해결: body(JSON) 방식으로 변경하고 API 스펙에 맞게 타입 수정
- **결제가 실패해도 주문이 완료 상태로 남던 문제**
  → 원인: 결제 승인 시 금액 검증 절차 부재
  → 해결: Toss 응답 금액과 주문 금액을 대조하고, 실패 시 상태를 되돌리는 로직 추가

**Tech** Java 17, Spring Boot 3.5.0, Spring Data JPA, Spring Security, MariaDB, Toss Payments

🔗 [kosa2025_MSA_final](https://github.com/YONGMINJO1/kosa2025_MSA_final)
